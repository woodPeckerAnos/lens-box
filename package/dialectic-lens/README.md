# @lsby/lens-box-dialectic-lens

基于**大模型结构化提取与本地确定性建模**的苏格拉底诘问法辩证分析透镜。

## 观察视角

不同于形式化断言结构的逻辑视角或剖析论证支持/攻击关系的论证视角，本透镜把一段发言当作**隐含内容（隐藏前提、假设、模糊定义、默认常识）的载体**来观察，回答三个问题：

1. **发言在背后依赖了哪些没有明说的内容？**（隐藏前提、假设、模糊的概念定义、被默认为真的常识）
2. **针对这些隐含内容，可以怎样展开苏格拉底式的诘问？**（围绕概念组织、每步锚定隐含内容的候选诘问链）
3. **诘问把发言者引导向哪个内在理念？**（以定义法追问概念本质，得到理念重述与本质定义尝试，或诚实的困惑判定）

三条核心结构原则：

- **两点先定，中间连线**：每条诘问链的**起点**（质疑哪些隐含内容）与**终点**（上升到的内在理念与本质定义尝试，或无法上升的困惑判定）在链设计之初即已确定；中间的诘问步骤只是实现两点间连线的引导过程，不是追问中动态涌现的产物。
- **追问链是分析结果，不是实际行为**：透镜输出候选诘问集，是否实际发问、何时发问由上层调用方自行取舍，透镜自身永不执行追问。
- **每步追问仅对其锚定的隐含内容负责**：步骤之间无对话依赖、不建模"预期回答"，因此真实追问中发言人的回答一旦偏离预设，剩余诘问不会跑偏、不会丢失对隐含前提的质疑。

职责划分：**LLM 只负责语义工作**——推测隐含内容、确定理念终点、设计引导诘问；原文定位、结构校验、引用完整性、索引查询、诊断与快照恢复全部由本地确定性代码完成。

## 范畴体系

| 范畴         | 取值                                                                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 隐含内容类型 | `hiddenPremise` 隐藏前提 · `assumption` 假设 · `unclearDefinition` 模糊定义 · `defaultCommonSense` 默认常识                                                                    |
| 诘问形式     | `definitionProbe` 定义追问 · `premiseProbe` 前提追问 · `clarificationProbe` 澄清追问 · `consistencyProbe` 一致性追问 · `counterexampleProbe` 反例追问 · `ascentProbe` 上升追问 |
| 链终点       | `ascent` 上升（内在理念 + 本质定义尝试） · `aporia` 困惑（无法上升的判定与原因）                                                                                               |

## 核心领域概念

- **`ImplicitContentItem`**：一条被识别出的隐含内容实体，内聚类型、涉及概念、自然语言重述与**逐字原文依据**（`quote` + `[start, end)` 字符区间），支持关键词匹配与快照导出。
- **`ElenchusChain`**：一条两点先定的候选诘问链，内聚环绕概念、固定起点（质疑的隐含内容标识集合）、固定终点（`ascent` 携带理念重述与本质定义尝试，`aporia` 携带原因注记）与引导步骤列表；构造时强制链不变量（起点标识唯一、每步锚定唯一且为起点集合的子集）。
- **`DialecticDocument`**：一次剖析的完整结果，聚合原文、隐含内容项、诘问链、来源标签、记录时间与提取来源（模型与提示词版本）；构造时重新校验每条原文依据与原文逐字一致、标识全局唯一、链起点全部可解析，并提供：
  - `getItemsByType()` / `getItemsByConcept()` / `listConcepts()`：隐含内容剖面（概念按表面形式精确匹配）；
  - `getMovesForItem()`：针对某隐含前提/不自知定义的全部诘问——动态追问中不丢失质疑的核心查询；
  - `findUnprobedItems()`：未被任何诘问链触及的隐含内容（追问遗漏诊断）；
  - `getAscentChains()` / `getAporiaChains()` / `getDestinationProfile()`：终点诊断与内在理念汇总。
- **`DialecticLens`**：无状态对外入口，基于 `@lsby/ai-agent`（接收标准 OpenAI 兼容客户端与模型配置）发起结构化提取并返回 `DialecticDocument`。
- **`buildDialecticDocument`**：纯本地构建函数，将固定提取结果离线构建为 `DialecticDocument`，供测试与自定义提取通道复用。
- **`canon`**：隐含内容类型、诘问形式与终点类别的中文标签目录，全部以全量 `Record` 映射表达，新增枚举时类型系统强制补齐。

## 最小示例

```ts
import OpenAI from 'openai'
import { DialecticLens } from '@lsby/lens-box-dialectic-lens'

let 透镜 = new DialecticLens({
  openaiClient: new OpenAI({ apiKey: 'ollama', baseURL: 'http://127.0.0.1:11434/v1' }),
  model: 'gpt-oss-20b',
  supportsFunctionCalling: true,
})

let 篇章 = await 透镜.analyze({ text: '……一段依赖隐含前提的发言……' })

for (let 链 of 篇章.getChains()) {
  链.getTargetItemIds() // 固定起点：质疑的隐含内容
  链.getDestination() // 固定终点：ascent 或 aporia
  链.getAscent() // 上升时返回 { idea, essentialDefinition }
  链.getMoves() // 引导步骤（每步锚定其质疑的隐含内容）
}

篇章.findUnprobedItems() // 未被追问的隐含内容
篇章.getMovesForItem(项标识) // 针对某项隐含前提的全部诘问
篇章.getDestinationProfile() // { ascent: n, aporia: m }
```

完整可运行示例见 [demo/basic-demo.ts](demo/basic-demo.ts)。

## 错误语义与副作用

- `analyze()` 会通过网络调用 OpenAI 兼容模型，**可能产生模型费用**；构建、查询、诊断与快照恢复均为纯本地操作。
- 输入为空、模型无法给出有效结构化结果、提取结果引用未知或重复临时标识、步骤锚定超出链起点集合、原文摘录无法按出现序号定位、快照中的依据与原文不一致等场景均**立即抛错**（Fail-Fast），不做静默兜底；网络、限流与中断异常原样向上传播。
- 引用完整性与锚定子集约束在结构化输出的 Schema 校验阶段（`superRefine`）即被拦截并反馈给模型重试修复，进入本地构建的数据必然通过校验；本地构建器与文档构造器仍独立重校验全部不变量。
- 重复调用 `analyze()` 会为相同文本生成新的篇章标识与记录时间；透镜不自动持久化任何结果。
- 快照携带 `snapshotVersion: 1` 与 `provenance`（模型名 + 提示词版本 `DIALECTIC_PROMPT_VERSION`），便于审计与复现；恢复快照时重新校验全部不变量。

## 适用边界

- **擅长**：演讲、论说文、访谈、辩论发言中隐含前提与不自知定义的挖掘，围绕概念组织的苏格拉底式诘问设计，以及作为上层真实追问（由调用方自行执行）的结构化输入。
- **不擅长（有意不做）**：本透镜**不做真伪评判与立场评分**，也**不执行任何追问**——诘问链与终点理念是分析产物（终点理念是分析师视角的判定，并非文本显式内容），一切实际发问与进一步解读交由上层调用方按需处理。
- **不擅长**：概念表面形式的同义归并（"正义"与"正当"被视为不同概念，概念索引按表面形式精确匹配）；对不依赖隐含内容的纯叙述文本会返回空文档而非编造结构。
