# 表达成团透镜

楼下汉堡店换了面包，肉饼总算不会一咬就滑出去。一个人随口说：“是啊，他们可算开窍了。”隔了两天，他提起河边另一家店，对方接了一句：“我还以为你要带我去楼下那家，前两天才夸人家开窍了。”

八晚里，“门口”和“开窍”各出现三次。前者散在三晚，后者落在这两次聊汉堡的时候。透镜可以定位到这两晚。读回对白，才能看出后一句接起了之前的玩笑。例子保留了“开窍”这个说法，店铺、地点和对白都已改写。

## 接口

`成团语料` 接收至少两篇非空文本。每个数组元素算一篇，由调用方选择章节、会话或有记录的日子。构造时抽取一次参照，之后可以连续查询多个表达。已有语言形式透镜或其他分析给出的词也可以直接拿来查。

```ts
import { 成团语料 } from '@lsby/lens-box-expression-clumping-lens'

let 语料 = new 成团语料(文档列表, { 种子: 1, 样本上限: 3000 })
let 结果 = 语料.观察('开窍')
if (结果.状态 === '已校准') {
  console.log(结果.总次数, 结果.覆盖篇数, 结果.成团分数)
  console.log(结果.分布, 结果.目标档位, 结果.参照)
}
```

每次观察都返回总次数、覆盖篇数、文档总数及逐篇计数（文档序号从 0 开始，仅列命中篇）。总次数为 0、仅 1～2 次、无合格参照桶时，返回相应的原因和 `null` 分数。已校准时同时给出泊松期望、校准期望、实际采用的档位和样本数，便于回查。

## 核心概念与计算

- **文档覆盖。** 同一篇里每次重现都增加总次数 `cf`，覆盖篇数 `df` 只增加一次。查询按原始字面、区分大小写、允许重叠。换行和文档边界隔开表达。
- **同频参照。** 设文档数为 `N`。等强度泊松模型给出的覆盖参照为 `E(cf) = N × (1 − exp(−cf/N))`。在原文中随机选位置与长度，抽取 2～4 个 Unicode 码点的字串，去重，默认上限 3,000 个、最多尝试上限的四倍。较常见的字串被抽中的机会更大。跳过跨行及两端带空白的片段。固定文档顺序、文本、选项和实现版本即可复算。
- **校准。** 出现至少三次的参照串按 `floor(log2(cf))` 分档。每档至少五个不同字串，取 `df/E(cf)` 的上中位数作为校准系数 `u`。目标所在档不足时取最近有效档，等距时取小档。校准期望 `E(cf) × u` 是经验比较值，跨频数借用时可能超过文档数。
- **成团分数。** `C = ln(E(cf) × u / df)`。例如 `C ≈ 0.69` 表示实际覆盖篇数约为校准参照的一半。零附近表示相当，负值表示更分散。参照串来自整份语料，符合抽样条件的查询词也可能位于参照桶内。

## 如何解释结果

可以从写作样本中找出集中在少数章节的惯用语，也可以为联想图的标签补上覆盖分布。确定一种说法是否值得唤起某段经历，还需要原文和具体使用场景。文档的长度、语言构成和模板也会影响结果。换了切分单位就应重新建立参照，比较不同语料时应同时报告分母和参照。该指标对相邻两篇与相隔很远的两篇采用同一种覆盖计数。

Hikaru 的联想入口另外结合一般词频与低频保护。这里将可复用的覆盖统计独立出来，使用统一的字面计数与 TypeScript 的确定性采样；与 Hikaru 的别名边界、大小写处理和 Python 抽样序列有差异。两种实现共享校准公式，具体词的数值可能不同。[Hikaru 的原实现](https://github.com/ikarugaikoi/hikaru-memory/blob/main/.tools/_koyori.py)
