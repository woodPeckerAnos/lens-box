# @lsby/lens-box-language-form-lens

基于**本地分词、词性标注与表面形式统计**的非大模型中文语言形式分析透镜，全程同步运行。

## 观察视角

不依赖大语言模型或外部词向量，保留虚词、标点与原始断句结构，从可观察的语言表层回答三个问题：

1. **文本偏爱哪些词与虚词？**（保留虚词统计词频、词性分布，以及按 `d / p / c / u / e / y / o` 界定的操作性虚词词项）
2. **句子内部有哪些表面搭配习惯？**（在句内滑窗提取相邻词搭配与固定长度的连续词性短序列）
3. **文本的标点与句段节奏如何？**（统计 Unicode 标点分布、非空白码点句长与段长分布，保留有序句段节奏，并支持跨篇章与跨语料对比）

## 核心领域概念

- **`语言形式透镜`**：无状态的同步剖析入口，保存观察配置（`词性序列长度`、`每项例证上限`），将输入文本分析为 `语言形式篇章`。
- **`语言形式篇章`**：单篇文章的形式分析结果，保存原文、有效词项、句段统计与有序节奏，支持导出独立快照、从快照严格恢复（含 Zod 校验与重算核对），以及通过 `对比另一篇章()` 逐表比较频率差异。
- **`语言形式语料`**：由同配置的一篇或多篇 `语言形式篇章` 聚合而成的语料集合，按实际计数与分母汇总频率、保留各篇节奏，支持快照导出恢复与 `对比另一语料()`。

## 适用边界

- **擅长**：中文散文、小说、台词与议论文的用词习惯、虚词倾向、标点偏好、句段长短节奏观察，以及多文本/多语料间的形式差异对比。
- **不擅长**：深层语义理解、修辞与讽刺判定、作者身份鉴定，以及强依赖复杂英文缩写或专业领域新词的精确切分。

## 统计口径与配置

- **词项与虚词**：使用本地 `@node-rs/jieba` 分词与词性标注，保留原始大小写、数字与虚词，不做停用词过滤或词干归一化；仅统计含 Unicode 字母或数字的词项，符号与 emoji 不计入词项。
- **句段与偏移**：按换行符切段并略过全空白行，依据中文常见句末标点切句；句长与段长以**非空白 Unicode 码点数**计量。每条例证保留原文的 UTF-16 左闭右开偏移与所在篇/段/句序号。
- **配置与快照**：`词性序列长度` 支持 `2～4`（默认 `3`），`每项例证上限` 支持 `1～20`（默认 `3`）。所有频率表均附带 `分母`（0～1 未舍入）；快照恢复要求使用相同版本的 `@node-rs/jieba` 词典以确保重算一致。
