# @lsby/lens-box-association-lens

基于**大模型结构化提取与原文逐字证据校验**的文本联想关系观察透镜，用于捕捉文本中“从什么想到什么”的连接脉络。

## 观察视角

不预设固定的领域分类词表，由注入的外部模型识别文本中的思维跳跃与意象联结，并通过代码严格校验引文与图结构，回答三个问题：

1. **联想涉及哪些对象与领域？**（识别触发节点、目标节点及其自由领域标签，区分真正联想与单纯叙事推进或共现）
2. **节点之间如何连接并发挥作用？**（提取连接依据、连接方式、表达作用，以及限定在原文内的后文发展状态：`延续 / 未见延续 / 无法判断`）
3. **多篇文章的联想习惯有何差异？**（汇总跨篇章的连接方式分布与有向领域转移 `[源领域, 目标领域]`，保留各篇网络与证据位置）

## 核心领域概念

- **`联想透镜`**：无状态的模型观察入口，基于 `@lsby/ai-agent` 接收调用方注入的 OpenAI 兼容客户端与模型配置，将结构与引文校验错误反馈给模型重试，最终产出 `联想篇章`。
- **`联想关系`**：单条有向联想边，关联源节点与目标节点，内聚连接方式、连接依据、表达作用、后文发展及对应原文证据。
- **`联想篇章`**：单篇文章的联想网络模型，支持按条件 `查询关系`、沿有向边遍历 `获得联想链`，以及快照导出、`从快照恢复` 与人工结果的 `从观察结果创建`。
- **`联想语料`**：由篇章标识唯一的 `联想篇章` 集合（允许零联想篇章），按字面相同的标签统计连接方式与领域转移，支持快照导出与恢复。

## 适用边界

- **擅长**：散文、小说、随笔、诗歌与评论中的意象跳跃、比喻联想、跨领域联结提取及多篇联想模式对比。
- **不擅长**：纯客观说明文或无联想的流水账；库不负责长文自动切分，调用方需自行控制模型上下文与输出预算。

## 校验口径与配置

- **原文定位与图约束**：完整保留原文（含首尾空白），通过 `{ 引文, 出现序号 }` 生成精确的 UTF-16 `[起点, 终点)` 切片；空白引文、错引、越界、自指、孤立节点、同源同目标同方式的重复关系以及违背先后顺序的“延续”均会报错。
- **客户端与遍历边界**：支持 `最大校验重试次数`（默认 `3`，0～100）、`温度`、`最大输出token`、`回调` 及中断信号；`获得联想链` 默认最大深度 `10`、最大链数 `100`（上限分别为 `100` 与 `10000`）。
- **演示入口**：`demo` 运行离线人工结构化示例；`demo:model` 默认连接本地 Ollama（`http://127.0.0.1:11434/v1`、`gpt-oss-20b`）运行真实模型演示。
